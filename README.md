# Expense Tracker — tanulóprojekt

Személyes kiadáskövető, ami lépésről lépésre bővül:

1. **Parancssoros script** (jelenlegi állapot) — Python alapok, JSON fájlba mentés
2. Web API (Flask/FastAPI)
3. Böngészős felület
4. Deploy Vercelre, automatikus deploy git push-ra
5. Adatbázis + (opcionális) mobilapp

## Használat

```bash
python main.py add 2500 étel --note "ebéd"
python main.py list
python main.py summary
```
